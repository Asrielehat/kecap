课答 Kecap v1.1.1 使用说明
============================

课答是一款基于 RAG 技术的 AI 学业辅导工具。
上传课程资料（教材、课件、笔记），即可获得精准、可溯源的 AI 答疑。

【快速开始】

1. 准备 API Key
   - DeepSeek（LLM）：https://platform.deepseek.com
   - SiliconFlow（Embedding）：https://siliconflow.cn
   注册后在对应平台创建 API Key。

2. 配置
   - 将 .env.example 复制一份，重命名为 .env
   - 用记事本打开 .env，填入你的 API Key：
     LLM_API_KEY=sk-你的deepseek-key
     EMBEDDING_API_KEY=sk-你的siliconflow-key

3. 启动
   - 双击 课答.exe
   - 浏览器会自动打开 http://localhost:8000

4. 使用
   - 左侧创建课程 → 上传课件（支持 PDF/PPT/DOCX/MD）
   - 中间聊天区提问，AI 基于课件内容回答
   - 选中回答中任意文字，点击追问按钮进行深入提问
   - 追问弹窗内可继续追问（嵌套追问）

5. 关闭
   - 关闭控制台黑窗口即可

【新功能 v1.1.1】
- 🛡️ 启动检测：自动检测残留僵尸进程，显示 PID 方便清理
- 🐛 修复：重复启动时可能连接到已卡死的旧实例导致页面无响应

【新功能 v1.1.0】
- 🔍 上下文隔离追问：选中文字即可弹出追问窗口
- 🔗 嵌套追问链：追问弹窗内可继续追问
- 📝 对话历史管理：自动保存，侧栏切换
- 🎨 拖拽式多弹窗：可同时打开多个追问窗口

【注意事项】
- 需要联网（调用云端 AI API）
- 首次上传文档后需稍等片刻进行向量化处理
- data/ 和 uploads/ 目录由程序自动创建，请勿删除
