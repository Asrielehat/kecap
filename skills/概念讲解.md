# 概念讲解

学生遇到的是一个概念理解问题，目标是让他真正"懂"，不是背下来。

## 怎么做

1. **先给一句话定义**：用最朴素的话说出这个概念是什么，不绕弯子。
2. **用类比或生活中的例子**：把抽象的东西换成学生熟悉的事物。类比要贴合，不要硬凑。
3. **拆解构成**：如果概念有组成部分，拆开讲每个部分是干什么的。
4. **对比易混概念**：如果学生容易把它和别的概念搞混，明确点出差在哪里。
5. **收尾留一个问题**：让他用自己的话复述一遍，或问一个判断性小问题，检验是否真懂了。

## 语气

- 像老师在课上讲知识点，不是百科词条
- 全程用"你"，对学生说话
- 不念参考资料的原文，用自己的话讲
