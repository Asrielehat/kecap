# 🛠 kecap 技能库（Skills）

这里是「课答」的内置技能目录。放在这个文件夹里的每个 skill 都会被 AI 自动加载、根据学生的问题自动调用，**所有用户都能用到**。

## 如何添加一个 skill

1. 在这个文件夹里新建一个 `.md` 文件（或建一个 `skill名/` 文件夹，里面放 `SKILL.md`）
2. 文件顶部用 `---` 写 frontmatter，格式：

```markdown
---
name: 技能名
description: 当学生问什么类型的问题时使用这个技能（AI 靠这段描述判断要不要调用）
---

# 技能名

这里是技能的详细指令，告诉 AI 具体应该怎么做……
```

3. 保存后**重启服务**即可生效（skill 在启动时加载）

## 规则

- `name`：技能名称（显示在前端「🛠 使用了 Skill：xxx」标签里）
- `description`：**很重要** —— AI 根据它判断何时使用该技能，写清楚适用场景。建议把触发词放在引号里（如 `「用费曼视角」「解释一下」`），这样即使 AI 忘了报技能名，系统也能通过触发词识别
- `mode`（可选）：限定技能在哪种聊天模式生效。`mode: learning` = 只在学习模式用；`mode: query` = 只在询问模式用；不写 = 两种模式都能用
- 正文：技能的完整指令，AI 会把它当作行为准则来调整回答方式
- 每个 `.md` 文件就是一个技能；`README.md` 不会被视为技能
- 不想要的技能直接删掉文件即可
